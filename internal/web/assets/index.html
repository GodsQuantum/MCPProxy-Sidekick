Credentials

Replace API keys without exposing the stored secret back to the browser.

OAuth

One click opens a visible sign-in tab. Loopback-only providers use the protected Cloud browser.

Agent Tokens

Give agents only the upstreams and permission tiers they need.

Secret handling

Full credentials are never returned by Sidekick after submission. The UI stores only masked previews and SHA-256 fingerprints.

Agent isolation

MCPProxy Agent Tokens scope upstream visibility and read/write/destructive permission tiers. Profile pinning is server-enforced.

Browser security

State-changing calls require CSRF + trusted Origin. Sessions use HttpOnly, Secure, SameSite cookies.

Container posture

No Docker socket. Non-root. Read-only root filesystem. Dropped capabilities. OAuth browser is reachable only through the authenticated gateway.

Restore the control plane

Sidekick is intentionally stateless about secrets. Restore the containers, reconnect credentials, and MCPProxy remains the source of truth.

cp .env.example .env
docker compose up -d
open https://mcp.example.com/control/

Public examples use documentation-only values. Never commit your production overrides or secrets.
